# Experiment: Data Visualization Using Orange

## Aim
To perform data visualization using the Orange Data Mining tool and represent data graphically to identify patterns, trends, and relationships.

## Requirements
- Computer or laptop
- Orange Data Mining software
- Dataset in CSV or tabular format

## Algorithm
1. Start the computer and open Orange Data Mining.
2. Create a new workflow.
3. Add the File widget and load the required dataset.
4. Connect the File widget to the Data Table widget to view the dataset.
5. Add a suitable visualization widget, such as Bar Plot, Scatter Plot, or Distributions.
6. Connect the data source to the visualization widget.
7. Select the required attributes and customize the visualization.
8. Analyze the graph to identify patterns and relationships.
9. Save the workflow for future use.
10. Stop.

## Description
Orange is an open-source visual programming tool used for data analysis, machine learning, and data visualization. It provides a graphical interface in which users can build workflows by connecting widgets without writing program code.

The File widget is used to import datasets, while the Data Table widget displays the data in tabular form. Visualization widgets help represent the dataset graphically.



## Procedure
1. Open Orange Data Mining.
2. Drag the File widget onto the workflow canvas.
3. Load a suitable dataset.
4. Connect the File widget to Data Table to inspect the records.
5. Add a Bar Plot or another suitable visualization widget.
6. Connect the File widget to the selected visualization widget.
7. Choose the attributes to visualize.
8. Observe and analyze the generated graph.
9. Save the workflow as an `.ows` file.

## Result
Thus, data visualization was successfully performed using Orange Data Mining, and the dataset was represented graphically to understand its patterns and distributions.
