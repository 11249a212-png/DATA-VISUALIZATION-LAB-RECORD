Experiment No. 2B: Experiment Details

Aim:
To create a bar graph using Python's Matplotlib library to represent and compare values across different categories.

Description:
Data visualization is the process of presenting data through graphical representations such as charts, graphs, and diagrams. A bar graph is one of the most commonly used visualization techniques for comparing values among different categories.

In a bar graph, rectangular bars represent the values of different categories. The height of each bar indicates the corresponding value. Bar graphs make it easy to compare quantities and identify the highest and lowest values in a dataset.

Applications:
1. Comparing sales of different products.
2. Representing students' preferences for programming languages.
3. Comparing population across different regions.
4. Analyzing survey results.
5. Presenting business and statistical information.

Algorithm:
1. Start the program.
2. Import the Matplotlib pyplot module.
3. Define the categories and their corresponding values.
4. Create a bar graph using the bar() function.
5. Add a title and label the X-axis and Y-axis.
6. Display the graph using the show() function.
7. Stop the program.

Program Explanation:
1. Matplotlib is imported to create the graph.
2. The category list contains the names displayed on the X-axis.
3. The values list contains the numerical data represented by the bars.
4. The bar() function creates a vertical bar graph.
5. The title() function adds a title to the graph.
6. The xlabel() function labels the horizontal axis.
7. The ylabel() function labels the vertical axis.
8. The show() function displays the generated graph.

Sample Output:
A vertical bar graph is displayed with programming languages on the X-axis and the number of students on the Y-axis.

The graph compares Python, Java, C, C++, and JavaScript using the values 40, 30, 25, 20, and 35, respectively.

Python has the highest value, while C++ has the lowest value.

Result:
The bar graph experiment demonstrates how Python's Matplotlib library can be used to visualize and compare categorical data effectively. The graph presents the values clearly and helps identify differences between categories.
